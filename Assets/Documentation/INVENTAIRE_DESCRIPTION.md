# 📦 INVENTAIRE — Prototype 2 (Style Solo Leveling)

## 🖤 Fond général
- Fond **noir abyssal** avec des reflets **bleu nuit**
- Effet de **brume violette** qui flotte doucement
- Bordures en **bleu électrique néon** qui pulsent

## 🦠 Section Mutations / Pouvoirs
| Pouvoir | Couleur |
|---|---|
| Griffes Whipfist | 🔵 Bleu électrique |
| Bouclier de masse | 🟣 Violet foncé |
| Bras marteau | 🔴 Rouge sang |
| Tentacules | 🟢 Vert toxique |
| Camouflage | ⚪ Blanc fantôme |

## 💀 Section Biomasse *(santé/énergie)*
- Jauge remplie d'un liquide **vert lime** qui bouillonne
- Contour **vert fluo** avec effet de **pulsation**
- Quand plein → particules **dorées** qui s'échappent

## ⚔️ Section Compétences actives
- Icônes en **hologramme bleu/violet**
- Fond de chaque icône : **noir avec bordure violette**
- Compétence équipée → halo **bleu brillant** autour de l'icône
- Compétence verrouillée → icône grisée avec cadenas **rouge**

## 🧬 Section Évolution *(style Solo Leveling)*
- Barre de progression **violet sombre → violet lumineux**
- Effet de **foudre dorée** quand tu débloques une mutation
- Texte en **blanc brillant** avec ombre **bleue**
- Points d'évolution affichés en **or**

## 🗃️ Section Objets consommables
- Fond **gris foncé métallique**
- Objets rares → bordure **violette**
- Objets communs → bordure **bleue**
- Objets légendaires → bordure **dorée** avec effet de flamme

## 🎮 Contrôle
- Appuyer sur la touche **3** du clavier alphabétique pour ouvrir/fermer l'inventaire
- Appuyer sur **Échap** pour fermer rapidement si l'inventaire est ouvert

## 💡 Notes d'intégration
- Attache `InventoryManager` à un objet de la scène UI
- Assigne `inventoryPanel` au panneau d'inventaire
- Le panneau est masqué automatiquement quand l'inventaire est fermé
- Le jeu se met en pause lorsque l'inventaire est ouvert (configurable)
